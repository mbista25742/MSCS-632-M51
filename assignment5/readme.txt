# Assignment 5: Ride Sharing System Implementation

This folder contains the deliverables for Assignment 5, which involved implementing a Ride Sharing System in both Smalltalk (Pharo) and C++.

## Contents

* **report.pdf**: This file contains the comprehensive report detailing the implementation, design choices, and demonstration of Object-Oriented Programming (OOP) principles (encapsulation, inheritance, and polymorphism).
* **pharo_code.zip**: This compressed file includes the Pharo Smalltalk code for the Ride Sharing System. It contains the image and changes files.
* **screenshots.zip**: This compressed file contains screenshots showcasing various aspects of the implementation, including code snippets, test results, and demonstrations of OOP principles.
* **cpp_code.zip**: This compressed file contains the C++ code for the Ride Sharing System. It includes the header (.h) and source (.cpp) files.

## Overview

The assignment required the development of a Ride Sharing System with functionalities to manage rides, drivers, and riders, demonstrating the application of OOP concepts in two different programming paradigms. The report provides a detailed explanation of the implementation and how the required functionalities were achieved.

## Instructions

1.  **Review the report.pdf** to understand the assignment requirements and the implementation details.
2.  **Extract the pharo_code.zip** to access the Smalltalk implementation. You will need a Pharo Smalltalk environment to run the code.
3.  **Extract the cpp_code.zip** to access the C++ implementation. You will need a C++ compiler (e.g., g++) to compile and run the code.
4.  **Extract the screenshots.zip** to view the screenshots referenced in the report.
